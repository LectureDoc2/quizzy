Quiz Tools

Check a quiz before a lecture, and encrypt it for publication in a deck. These are the same checks the server runs and the same cipher tools/encrypt-quiz.js uses — running here, in this tab. Nothing is uploaded: your quiz file and your password never leave the browser.

This page is not being served over HTTPS (or from localhost), so the browser withholds the Web Crypto API. Encryption and secret generation are unavailable; validation still works. Open the page over HTTPS, or use node tools/encrypt-quiz.js.

Validate a quiz

Runs the structural check the server performs before it will create a room, and additionally warns about a missing or weak secret — the field that keeps a participant from reconstructing the quiz JSON and deriving your presenter token. Equivalent to node tools/validate-quiz.js.

Encrypt a quiz

Validates the quiz, then encrypts it with AES-GCM and a key derived from your password with 600,000 PBKDF2 iterations — so the derivation takes a noticeable moment here, and an offline guessing attack on the published file takes a great deal longer. The result downloads as <name>.encrypted.txt, ready to be referenced from a deck.

Generate a secret

32 random characters for the quiz's top-level secret field, from the browser's cryptographic random source. The same thing openssl rand -base64 24 gives you, without leaving the page.
