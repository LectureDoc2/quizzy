Practice on Your Own

Practice quizzes can be played alone, without a presenter: the server shows each question, and after every answer moves on by itself.

Preparing a Quiz

Quiz Tools checks a quiz file against the same rules the server applies, and encrypts one for publication in a slide deck. Both run in your browser — the quiz and the password are not uploaded anywhere.
